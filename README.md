# Sorry, I Heard That Wrong

Entry for the make.fun bounty **"Sorry, I Heard That Wrong"**
(`u-kiencx-sorry-i-heard-that-wrong-1858c729`).

## The entry

One line, at most 140 characters: the apology a smart speaker gives its
owner after it mishears them.

## Run

```sh
python3 main.py
```

`main.py` writes the line to `output/entry.txt` (and to `/output/entry.txt`
when that directory exists, which is where the make.fun grader reads the
artifact), prints it, and asserts it is 1–140 characters.
